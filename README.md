# TripMaster Releases

Official distribution repository for TripMaster, an AI travel-planning desktop application.

## Download status

TripMaster is in the planning stage. **No installable version has been published yet.**

When builds are available, Windows installers and version notes will appear on the [Releases page](https://github.com/SamChengYo/TripMaster-Releases/releases).

## Planned platform

- Windows desktop, with global travel planning and multilingual support.
- Visible browser assistance for research and reservation forms.
- User confirmation before payments and other consequential actions.
- In-app version checks, optional update downloads, and installation followed by restart.

## Repository purpose

This public repository will contain installers, release notes, and update metadata. Application source code is maintained in a private development repository.

Users will not need a GitHub account or GitHub token to download public release assets.
